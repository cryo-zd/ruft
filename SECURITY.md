# Security Policy

## Supported Versions

Security fixes are applied to the latest released `0.x` version. Development
branches may change without compatibility guarantees.

## Reporting a Vulnerability

Do not open a public issue for a suspected consensus, durability, recovery, or
memory-safety vulnerability. Report it privately to the project maintainers
with a minimal reproduction, affected version, expected and observed behavior,
and any relevant logs or traces.

Until a dedicated security contact is published, use the repository host\x27s
private vulnerability-reporting feature. If that feature is unavailable, contact
the maintainers through the email address listed in the package registry.

Reports are acknowledged within seven days when contact information is valid.
Please allow maintainers time to reproduce, assess affected deployments, prepare
a fix, and coordinate disclosure before publishing details.
